# Korea Nurse Scheduler via AI Tools Prototype

Educational prototype for nurse scheduling automation.

The project explores schedule generation, hard and soft constraint evaluation,
local search, and AI-assisted tuning for ward staffing plans. Good input data
and carefully modeled constraints remain the most important part of schedule
quality.

## Cleanup Note

Local runtime artifacts such as SQLite databases, trained model binaries,
temporary Excel uploads, and IDE settings are intentionally excluded from the
repository.
